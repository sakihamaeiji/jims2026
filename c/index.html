504社 開示編成カード

有価証券報告書（有報）と統合報告書等の任意報告書について、媒体ごとの役割分担（Allocate）と媒体間のつながり（重複・共通性 Repeat、補完 Expand、接続 Link）を企業ごとに並べました。各行の目盛りには自社を除いた同業中央値を置いています。社名・証券コード・業種で検索できます。総合点や順位はありません。

パネル全体の水準
該当する企業がありません社名の一部、証券コード4桁、業種名で試してください。

カードの読み方

各行の目盛りは 自社の値、 同業中央値です。同業中央値は同じ業種・同じ年から自社を除き、その指標を測定できた他社が9社以上あるときだけ表示します。目盛りの範囲はすべて0〜1です。

ALLOCATE
主題配分差 A　辞書の10主題が付いた主張ブロックについて、媒体ごとに正規化した主題構成比の差（全変動距離）。0は同じ配分、1は共通する配分がない状態です。差の大小に優劣はありません。どちらかの媒体で主題を観測できない企業年は欠測にしています（0.5などで代用しません）。
REPEAT
共通コア被覆 C　抽出した有報の主張候補のうち、任意報告書側に同じ主題で対応スコアの条件を満たす候補が見つかった割合です。分母は企業あたり数件のことが多く、値は1/4刻みのような離散値になります。全文の一致率ではありません。
EXPAND
追加説明率 E　自動で確認した対応候補（Repeat＋Expand）のうち、任意報告書が機能・根拠を追加しているか、有報の1.35倍以上の長さで説明している割合です。確認候補が3組未満の企業年は値を出しません。同業中央値も3組以上の企業に限ります。
LINK
媒体名言及 L　有報→任意、任意→有報のそれぞれで、相手媒体の名称への言及を検出したか（0／0.5／1）。読者が実際に移動できるか、移動したかは測っていません。点線のチップ「参照先候補」は、ページ番号・章・URL等を伴う言及の候補です。
RECONCILE
数値条件の照合はカードに載せていません。指標・単位・目標／実績・範囲・対象年・基準年がそろう自動比較は1,512企業年で4件にとどまり（4件とも値は一致）、企業ごとの比較に使える量ではないためです。
この表にないもの　総合得点、順位、星評価、偏差値。四つの値は合成せず、別々の観察項目として読みます。
自動候補であること　値は公開文書から辞書とルール照合で自動抽出した候補で、人手の正解判定による精度評価は行っていません。有報は既存のテキストブロック、任意報告書は候補ページを対象にしており、両媒体の全文を同じ範囲で比べたものではありません。編集判断に使うときは原文とページを確認してください。
同業中央値　追いつくべき正解ではなく、原文を見比べる箇所を選ぶための参照点です。業種は分析台帳の業種区分で、表記揺れ1件（倉庫・運輸関連）を名寄せしています。
欠測　欠測は0で埋めていません。本文テキストを十分に取得できなかった文書を含む企業年（例：カゴメ2025）は、該当する値を欠測にしています。
