03測定仕様

記号：企業 i、報告年 t、媒体 Y（有報）と V（同一企業年の任意報告書の集合）、ブロック b、主題 k。四つの観点（A・C・E・L）は、IMCの共通性・補完性・接続を別々に観察するための確認観点で、独立した因子や加算できる総合得点ではありません。数値条件の照合（整合性）は参考として記載し、比較には含めていません。

ALLOCATE
主題配分差 A w_bk = min(500, max(25, 文字数_b)) / |T_b| ・ 1{k ∈ T_b}　　A_it = ½ Σ_k | p_V,kit − p_Y,kit | T_b は10主題辞書で付いたラベル集合。主題が付かないブロックは分母に入れません。媒体内で正規化した構成比（Σ_k p = 1）どうしの全変動距離で、値域は0〜1。媒体全体の主題重みが0なら分布が未観測なのでAを欠測にします（1,512企業年中4企業年）。同一企業年の複数の任意報告書は、ブロック単位で統合してから正規化します。
REPEAT
共通コア被覆 C S(v,y) = .75 cos_TF-IDF(v,y) + .15 Jaccard(T_v,T_y) + .10 I(共通指標語) C_it = 同族条件を満たす対応のある有報ブロック数 / 対象の有報ブロック数 有報側の各ブロックから任意側でSが最大のブロックを選び、共通主題があり S ≥ .24（共通指標語があれば .19）を同族とします。分母には主題が付かない有報候補も含みます。任意側から数えるRepeat件数の比率とは別の量です。
EXPAND
追加説明率 E E_it = Expand / (Repeat + Expand) 任意側の各ブロックから有報側でSが最大の対応を選び（多対一）、同族の対応について、任意側にだけある機能（事例、価値創造、顧客価値、対話、指標・目標・実績、将来志向、戦略・方針）か根拠（施策事例・数値実績・数値目標）があるか、有報の1.35倍以上の長さならExpand。追加がなく TF-IDF cos ≥ .55 または文字3gram Jaccard ≥ .45 ならRepeat、残る同族対応も既存のfallbackでRepeatに含みます。確認候補が3組未満の企業年は値を表示しません。
LINK
媒体名言及 L と両方向 B L_it = { I(Y→V) + I(V→Y) } / 2 ∈ {0, .5, 1}　　B_it = I(Y→V) · I(V→Y) 相手媒体の名称への言及を方向別に検出します。Bの年次平均が両方向言及率で、Lの平均とは別です。水準2は参照文言または参照先、水準3はページ番号・章・URL等を伴う具体的参照先候補です（「Scope」「Group」のpはページと判定しません）。読者が移動できるか、移動したかは測りません。
参考
数値条件の照合（整合性） 数値整合候補率 = 厳格比較で値が等しい行数 / 厳格比較が可能な行数 同族の最良対応の中で、単一の百分率・明示的な対象期間・範囲・指標の下位区分・増減方向・基準年（GHG）がそろう候補だけを自動比較します。全34候補のうち通過は4件で、4件とも値は一致しました。旧版の差分3候補は、条件の異なる主張どうしの比較だったため除外しました。通過が4件と少ないため、企業・業種・時点の比較には含めていません。
CHANGE
企業内変化 Δ_M = M_i,2025 − M_i,2023（両年とも測定できた企業のみ） 差の平均と中央値を別々に示し、企業を単位に3,000回（seed = 120）再標本化した百分位区間を付けます。区間には抽出・分類・標本選択の不確実性は含まれません。離散的な指標（C、L、B）は中央値が0に張り付くため、増加・減少・不変の社数を併記します。

05限界

本研究が観察したのは公開文書の設計です。次の範囲は主張しません。

  • 01
    抽出範囲が非対称。有報はサステナビリティ等の既存テキストブロック、任意報告書はテーマ報告書または辞書で選んだ候補ページです。両媒体の全文を同じ情報範囲で比べた設計ではありません。検出しなかったことは、文書全体やウェブ上に存在しないことを意味しません。
  • 02
    辞書とルールによる測定。10主題の付与率は任意報告書で47–51%、有報で89–90%（主張ブロック数ベース）。Aは主題が付いた範囲に条件付きの配分差です。
  • 03
    人手の正解データがない。Repeat・Expand・媒体名言及・数値照合は自動候補で、精度は未評価です。
  • 04
    年度対応と本文取得。報告年は既存の対応ラベルで、会計期間の一致を人手確認していません。カゴメ2025など本文を十分に取得できない文書が残り、該当値は欠測です。
  • 05
    選択標本の記述比較。任意報告書を3年取得できた企業に限られ、上場企業全体の代表標本ではありません。制度導入の因果効果は識別しません。
  • 06
    受け手と組織は未測定。投資家の理解・行動、組織レベルのIMC実践、財務・マーケティング成果は測っていません。
読み方　主題配分差は相対配分の距離で、高い・低いに優劣はありません。対応候補がない段落を「新規情報」や「分断」とは呼びません。数値照合の候補は誤記の指摘ではなく、定義・範囲・時点を原文で確かめるための候補です。観点を合成した得点や企業の順位は作っていません。
